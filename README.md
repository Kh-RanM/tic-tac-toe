# Projekt: Tic Tac Toe
Technologien: HTML, CSS und JavaScript

Beschreibung:
In diesem Projekt entwickle ich ein interaktives Spiel
für zwei Spieler.

Ziel:
Ich möchte meine Frontend-Kenntnisse praktisch
anwenden und vertiefen.

Lernziele:
- Eine Website mit semantischem HTML strukturieren.
- Ein responsives Layout mit CSS Flexbox und Grid erstellen.
- Bilder und grafische Elemente richtig einbinden.
- Arrays zur Speicherung des Spielstands verwenden.
- DOM-Elemente mit JavaScript manipulieren.
- Klickereignisse mit addEventListener() verarbeiten.
- Die Spiellogik mit Bedingungen und Funktionen umsetzen.
- Gewinnbedingungen und Unentschieden erkennen.
- Das Spiel neu starten.
